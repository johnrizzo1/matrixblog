## Design Philosophy

The goal was to create a unique navigation experience that feels physical yet futuristic. The "SpinWheel" allows users to interact with the navigation menu as if it were a physical dial.

### Tech Stack
- **Vite**: For lightning-fast HMR.
- **Framer Motion**: For the spring physics of the wheel.
- **React Router**: For seamless SPA navigation.

The **Layout Transition** system ensures that the wheel persists across pages, morphing from a central hub to a corner navigation tool.
